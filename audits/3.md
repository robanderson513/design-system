# Audit: #3 — Create Semantic Tokens

## Ticket changes

This change adds a semantic token layer for consuming apps and limits the published package API to semantic values.

- Ticket: [#3](https://github.com/robanderson513/design-system/issues/3)
- Pull request: [#8](https://github.com/robanderson513/design-system/pull/8)

### Files changed

- `tokens/semantic/colors.json`: maps common color roles and surface, text, border, action, and status colors to the internal color ramps.
- `tokens/semantic/spacing.json`: adds semantic gap, padding, and margin scales.
- `tokens/semantic/typography.json` and `tokens/semantic/radius.json`: provide semantic aliases for typography and border-radius primitives.
- `dist/index.js`: exposes resolved semantic values for CommonJS consumers and retains `color.primary`.
- `dist/tokens.css` and `package.json`: add the CSS custom-property export and remove public primitive subpath exports; primitive source files are excluded from the published package.
- `preview.html`: previews semantic color roles instead of primitive ramps.
- `README.md`: documents the semantic package API and CSS export.
- `audits/3.md`: records this ticket's implementation and validation.

Color token groups use nested lowercase names for action states and status roles. `color.primary` remains available as a compatibility alias.

## Validation

- Parsed all token JSON and package metadata.
