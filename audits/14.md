# Audit: #14 — Add Recipe App Theme

## Ticket changes

This change adds the recipe app's primitive palette and an optional recipe brand override for the existing light/dark semantic themes. The recipe palette uses clay as its warm surface foundation while retaining stone as a general-purpose neutral. The default brand and its token aliases remain unchanged.

- Ticket: [#14](https://github.com/robanderson513/design-system/issues/14)
- Pull request: Not created.

### Files changed

- `tokens/primitives/colors.json`: adds sage, terracotta, harvest, and stone ramps with shades 50–950, plus the clay ramp from shades 50–950.
- `tokens/semantic/colors.json`: adds recipe light/dark brand mappings for brand, clay-based surfaces, text, borders, actions, and selected states; shared status roles remain inherited. Adds action text roles.
- `dist/index.js` and `dist/tokens.css`: expose the recipe values to CommonJS and CSS consumers and support `data-brand="recipe"` independently of `data-theme`.
- `preview.html`: adds brand/appearance selection, primitive ramp swatches, and resolved semantic role previews.
- `tests/theme.test.js`: checks ramp values, token reference resolution, compatibility, and recipe contrast pairings.
- `README.md`: documents recipe brand selection, warm clay surfaces, and behavior.
- `package.json`: bumps the package version to `1.0.2`.

## Validation

- `node --test tests/theme.test.js` passed with the clay ramp and updated recipe semantic mappings.
- Primitive and semantic color JSON parsed, and semantic references resolved.
- The CommonJS entry point was checked for package version `1.0.2`, the default compatibility alias, and updated recipe exports.
- Primary/secondary action text and primary/secondary/muted text against recipe surfaces were checked for 4.5:1 contrast.
- `npm pack --dry-run --json` confirmed the versioned package includes the shipped CommonJS and CSS outputs.
- `git diff --check` passed.
- No package build or token generation command is available; shipped `dist` files were updated directly.
