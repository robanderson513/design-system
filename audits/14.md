# Audit: #14 — Add Earth Palette Theme

## Ticket changes

This change adds the earth color palette for the existing light/dark semantic themes. The palette uses clay as its warm surface foundation and includes sage, terracotta, and harvest accents, while retaining stone as a general-purpose neutral. The default theme and its token aliases remain unchanged.

- Ticket: [#14](https://github.com/robanderson513/design-system/issues/14)
- Pull request: Not created.

### Files changed

- `tokens/primitives/colors.json`: adds sage, terracotta, harvest, and stone ramps with shades 50–950, plus the clay ramp from shades 50–950.
- `tokens/semantic/colors.json`: adds earth palette light/dark mappings for palette colors, clay-based surfaces, text, borders, actions, and selected states; shared status roles remain inherited. Adds action text roles.
- `dist/index.js` and `dist/tokens.css`: expose the earth palette to CommonJS and CSS consumers and support `data-palette="earth"` independently of `data-theme`.
- `preview.html`: adds palette/appearance selection, primitive ramp swatches, and resolved semantic role previews.
- `tests/theme.test.js`: checks ramp values, token reference resolution, compatibility, and earth palette contrast pairings.
- `README.md`: documents earth palette selection and warm clay surfaces.
- `package.json`: bumps the package version to `1.0.2`.

## Validation

- `node --test tests/theme.test.js` passed with the clay ramp and earth palette semantic mappings.
- Primitive and semantic color JSON parsed, and semantic references resolved.
- The CommonJS entry point was checked for package version `1.0.2`, the default compatibility alias, and earth palette exports.
- Primary/secondary action text and primary/secondary/muted text against earth palette surfaces were checked for 4.5:1 contrast.
- `npm pack --dry-run --json` confirmed the versioned package includes the shipped CommonJS and CSS outputs.
- `git diff --check` passed.
- No package build or token generation command is available; shipped `dist` files were updated directly.
