# Audit: #2 — Create Utility Primitives

## Ticket changes

This change adds reusable DTCG utility primitives alongside the existing color tokens.

### Files changed

- `tokens/primitives/spacing.json`: adds a dimension scale for spacing.
- `tokens/primitives/typography.json`: adds font-family stacks, font sizes, font weights, and unitless line heights.
- `tokens/primitives/radii.json`: adds border-radius dimensions.
- `package.json`: exposes the new token files as package subpaths.
- `dist/index.js`: includes the utility groups in the CommonJS entry point while preserving `color.primary`.
- `README.md`: documents the available utility categories and package usage.
- `audits/2.md`: records this ticket's implementation and validation.

## Validation

- Parsed the token JSON files and verified the package entry point and token subpath imports with Node.js.
- `npm.cmd pack --dry-run --json` confirmed the new token files are included in the package.
- `git diff --check` passed.
- No automated tests were run; the repository has no package scripts or test suite.
