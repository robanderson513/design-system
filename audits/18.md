# Audit: #18 — Add Button Styles

## Ticket changes

This change establishes a complete baseline button style and role-based variants, with shared spacing and typography and semantic color roles supplied by the active baseline or specialty theme. The primary is filled; the secondary is a flat surface-colored outlined treatment so it remains lower emphasis.

- Ticket: [#18](https://github.com/robanderson513/design-system/issues/18)
- Pull request: Not created.

### Files changed

- `dist/common.css`: adds complete baseline, filled, tonal, elevated, outlined, primary-colored text, neutral text, and icon-only button styles, including theme-aware hover, pressed, disabled, and focus-visible behavior.
- `tokens/semantic/colors.json`, `dist/tokens.css`, and `dist/index.js`: define dedicated tonal container, hover, pressed, and text roles for all themes and use warm clay neutral tokens for earth light neutral-control hover and pressed states.
- `docs/components/buttons/README.md`: documents button structure, variant responsibilities, token mappings, theme behavior, and accessibility requirements.
- `docs/components/buttons/preview.html`: provides a visual comparison of constructed button variants across default and earth light/dark themes.
- `README.md`: adds concise pointers to button usage and the documentation structure.
- `AGENTS.md` and `docs/README.md`: provide a consumer-agent entry point and documentation index.
- `docs/components/colors/README.md` and `docs/components/colors/preview.html`: keep color palette guidance and the color preview in their own section.
- `.github/copilot-instructions.md`: points repository agents to the consumer guide and documentation layout.
- `package.json`: bumps the package version to `1.1.0` for the additive button component and token API, and includes consumer guidance, docs, and token sources in the published package.
- `tests/theme.test.js`: adds focused assertions for the button selectors and semantic token usage.
- `audits/18.md`: records the ticket implementation and validation notes.
