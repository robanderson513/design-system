# Audit: #10 — Add Light/Dark Theme Foundation and Accessibility States

## Ticket changes

This change addresses [issue #10](https://github.com/robanderson513/design-system/issues/10) by adding explicit light and dark semantic color themes, focus-visible tokens, interaction-state tokens, and opt-in CSS utilities.

- Pull request: [#12](https://github.com/robanderson513/design-system/pull/12)

### Files changed

- `tokens/semantic/colors.json`: defines light and dark semantic color roles and state values while retaining the existing light-role token paths.
- `tokens/semantic/accessibility.json`: defines theme-specific focus-ring colors, width, and offset.
- `dist/tokens.css`: exports themed variables and maps the existing semantic variables when `data-theme="dark"` is applied.
- `dist/common.css`: adds `.focus-ring` and state utility selectors backed by the exported variables.
- `dist/index.js`: exposes both semantic themes and accessibility tokens while preserving `color.primary`.
- `preview.html`: displays light and dark theme palettes side by side.
- `README.md`: documents theme selection, state utilities, and focus-visible behavior.
- `tests/theme.test.js`: adds focused checks for the theme tokens and package/CSS exports.
- `audits/10.md`: records this issue's implementation and validation.

## Validation

- `node --test tests/theme.test.js` passed.
