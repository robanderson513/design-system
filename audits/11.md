# Audit: #11 — Add base foundation styles and utility layer for app consumption

## Ticket changes

This change adds the package's foundational stylesheet layer so consuming applications can start building UI immediately without ad hoc resets or utility patterns. It is layered on the light/dark theme tokens and state utilities now present on `main`; those theme features are upstream work from issue #10, not changes attributed to this ticket.

- Ticket: [#11](https://github.com/robanderson513/design-system/issues/11)
- Pull request: not created in this session

### Files changed

- `dist/tokens.css`: adds the shared base CSS foundation for box sizing, inherited theme color, typography defaults, and text rendering while retaining the upstream light/dark variable mappings.
- `dist/common.css`: expands the reusable utility layer with display, spacing, color, border, radius, shadow, visibility, and text-alignment helpers; preserves the upstream focus and interaction-state utilities.
- `README.md`: documents the base CSS foundation and the additional utility classes available to app consumers alongside the existing theme usage guidance.
- `tests/theme.test.js`: adds focused assertions for the foundation CSS and common utility classes.
- `audits/11.md`: records the ticket implementation and validation notes.
