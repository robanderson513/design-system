# Audit: #21 — Refine Utilities

## Ticket changes

This update standardizes gap, padding, and margin around one numeric scale, removes inconsistent generic named spacing roles and utilities, and makes shadow utilities consume shared shadow tokens.

The removal of the named spacing roles and classes is a breaking package API change; the package version is now `2.0.0`. Consumers should migrate spacing use to numeric utilities such as `gap-4`, `p-4`, and `mb-4`.

- Ticket: [#21](https://github.com/robanderson513/design-system/issues/21)
- Pull request: Not created.

### Files changed

- `tokens/semantic/spacing.json`: exposes a shared numeric spacing scale for gap, padding, and margin.
- `tokens/primitives/shadows.json` and `tokens/semantic/shadows.json`: define small, medium, and large elevation values and their semantic roles.
- `dist/tokens.css`, `dist/common.css`, and `dist/index.js`: expose numeric spacing and shadow tokens, use numeric gap/padding/margin utilities, and remove generic named spacing aliases.
- `tests/theme.test.js`: verifies token exports and stylesheet usage.
- `README.md`: documents the numeric spacing utilities, default padding, and shadow tokens.
- `package.json`: marks the spacing API removal as a major version change.

## Validation

- `node --test tests/theme.test.js` — passed.
- All changed token JSON files parse successfully.
- CommonJS entry point exports the new 16px padding and shadow tokens while retaining the existing primary color alias.
- No package build or token generation command is documented; shipped files were updated directly.
